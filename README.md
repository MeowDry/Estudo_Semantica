# 🐈 Gatinhos

Fiz esse projetinho pra praticar HTML semântico de uma forma mais descontraida, so para relembrar ^^ pois boas praticas nunca é de mais  

A ideia foi aprender na prática:
- semântica
- estrutura HTML
- headings
- acessibilidade
- organização do código

Tudo isso usando um blog totalmente sério sobre gatinhos bobocas xD
